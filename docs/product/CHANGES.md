## What changed, by nature

1. **Rebrand** — every product identifier, environment prefix (`COOLIFY_` → `XLAUNCH_`), image
   name, path and logo now carries the Xlaunch name. Behaviour is unchanged. (commits `b543878`,
   `1e3b9bb`, `93b9491`)
2. **Tiers** — plans are sold as fixed-price tiers that grant a machine allowance, configured per
   instance; the inherited per-server pricing is no longer shown. (`cb7a6da`)
3. **Tax as a setting** — automatic tax and tax-id collection at checkout are off unless the
   instance turns them on. (`5aa7b83`)
4. **Deployment and documentation** — `deploy/`, `docs/product/`, `LICENSING.md`, `NOTICE.md`,
   `README.md`: added by Northlatch Labs LLC, no upstream code.
5. **Removed from the distributed tree** — internal tooling and planning documents that are not
   part of the product.
